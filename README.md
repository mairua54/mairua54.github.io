# Daisy Physics แบบจำลอง

แบบจำลองประกอบชีท Daisy Physics เผยแพร่ที่ https://mairua54.github.io/

- ต้นฉบับและวิธีทำงานอยู่ใน `src/` (อ่าน `src/README.md` ก่อนแก้อะไร)
- `index.html`, `<บท>/`, `sims/`, `q/` สร้างจาก `src/tools/build_site.py` ห้ามแก้ด้วยมือ
- `q/<รหัส>/` คือลิงก์สั้นที่พิมพ์ใต้ QR code ในชีท ห้ามลบหรือเปลี่ยนชื่อ เพราะ QR ที่พิมพ์แล้วแก้ไม่ได้
