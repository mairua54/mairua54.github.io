การขัดสีและการถ่ายโอนอิเล็กตรอน

เลือกวัสดุสองชนิดจากตารางที่ 1.1 แล้วกดถู ดูว่าอิเล็กตรอนย้ายไปทางไหน ย้ายกี่ตัว และวัตถุแต่ละชิ้นเหลือประจุเท่าใด ประจุรวมของระบบไม่เปลี่ยน

ภาพ

เครื่องหมาย + (แดง) และ − (น้ำเงิน) แต่ละตัวแทนประจุส่วนเกินจำนวนหนึ่ง ไม่ใช่อิเล็กตรอนตัวเดียว ภาพวาดเฉพาะประจุส่วนเกิน ส่วนที่ยังเป็นกลางไม่ได้วาด ลูกศรสีน้ำเงิน e− บอกทางที่อิเล็กตรอนย้ายตอนถู แถบล่างคือลำดับในตารางที่ 1.1

ลองทำ

1. ทำนายก่อน: ถูแผ่นเปอร์สเปกซ์ด้วยผ้าไหม

ก่อนเลือกในแบบจำลอง ให้เปิดตารางที่ 1.1 แล้วทำนายว่าแผ่นเปอร์สเปกซ์กับผ้าไหม ชิ้นใดมีประจุบวก จากนั้นตั้งวัตถุ ก เป็นแผ่นเปอร์สเปกซ์ วัตถุ ข เป็นผ้าไหม แล้วกดถู

คำตอบ แผ่นเปอร์สเปกซ์อยู่ลำดับ 3 ผ้าไหมอยู่ลำดับ 6 ลำดับน้อยกว่าคือเสียอิเล็กตรอนง่ายกว่า อิเล็กตรอนจึงย้ายจากแผ่นเปอร์สเปกซ์ไปผ้าไหม แผ่นเปอร์สเปกซ์มีประจุบวก ผ้าไหมมีประจุลบ ขนาดเท่ากัน

2. ประจุรวมของระบบเปลี่ยนไหม

ตั้งประจุของวัตถุ ก ก่อนถูเป็น 0 แล้วเลื่อนจำนวนอิเล็กตรอนไปมา สังเกตบรรทัดสุดท้ายของการคำนวณ จากนั้นตั้งประจุของวัตถุ ก ก่อนถูเป็น +20e แล้วเลื่อนอีกครั้ง

คำตอบ ประจุรวมคงเดิมเสมอ เท่ากับประจุรวมก่อนถู การขัดสีย้ายอิเล็กตรอนจากวัตถุหนึ่งไปอีกวัตถุหนึ่งเท่านั้น ไม่ได้สร้างประจุขึ้นใหม่ นี่คือกฎการอนุรักษ์ประจุไฟฟ้าในหัวข้อ 1.1

3. ตรวจ Ex. 1.2 ด้วยแบบจำลอง

กดปุ่ม "Ex. 1.2" แล้วเทียบตัวเลขบนหน้ากับคำตอบใน Ex. 1.2 ของชีต ปุ่มนี้ตั้งให้วัตถุ ก มีประจุ +3.2 × 10−18 C ก่อนถู และอิเล็กตรอน 50 ตัวย้ายจากวัตถุ ข ไปวัตถุ ก

คำตอบ qก = -4.8 × 10−18 C และ qข = +8.0 × 10−18 C ตรงกับชีต ประจุรวมยังเป็น +3.2 × 10−18 C เท่าเดิม สังเกตว่าวัตถุ ก เปลี่ยนจากประจุบวกเป็นประจุลบ เพราะอิเล็กตรอนที่ได้รับมามากกว่าประจุบวกที่มีอยู่เดิม

4. ถูวัสดุชนิดเดียวกันได้ประจุไหม

ตั้งวัตถุ ก และวัตถุ ข เป็นวัสดุชนิดเดียวกัน แล้วกดถู เกิดอะไรขึ้น และเพราะเหตุใด

คำตอบ ตามตารางที่ 1.1 ทั้งสองชิ้นอยู่ลำดับเดียวกัน ไม่มีฝ่ายใดเสียอิเล็กตรอนง่ายกว่า แบบจำลองจึงไม่ย้ายอิเล็กตรอน และไม่มีประจุส่วนเกิน การขัดสีจะให้ประจุก็ต่อเมื่อวัสดุสองชนิดอยู่คนละลำดับในตาราง (ในการถูจริง วัสดุชนิดเดียวกันอาจเกิดประจุได้เล็กน้อยจากความต่างของผิว แต่น้อยกว่าการถูวัสดุต่างชนิดมาก)

แบบจำลองนี้ใช้ลำดับในตารางที่ 1.1 ตัดสินทิศการย้ายของอิเล็กตรอนเท่านั้น ไม่ได้ทำนายว่าถูจริงแล้วจะย้ายกี่ตัว จำนวนอิเล็กตรอนที่ย้ายจึงเป็นค่าที่ผู้ใช้ตั้งเอง ในการถูจริง จำนวนขึ้นกับแรงกด พื้นที่สัมผัส และความชื้นในอากาศ จำนวนเครื่องหมาย + และ − ในภาพวาดตามสัดส่วนของประจุอย่างคร่าว ไม่ได้นับทีละตัว และภาพไม่ได้วาดตามมาตราส่วน ตัวเลขบนหน้าปัดเป็นเลขนัยสำคัญ 2 ตัว ส่วนชีตใช้ 2 ตัวในหัวข้อนี้เช่นกัน
