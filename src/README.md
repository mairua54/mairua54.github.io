# ต้นฉบับแบบจำลอง Daisy Physics

โฟลเดอร์นี้เก็บต้นฉบับทั้งหมดของเว็บ https://mairua54.github.io/ แชทใดก็ตามที่มาทำแบบจำลองเพิ่ม ต้องอ่านไฟล์นี้ทั้งหมดก่อนแก้อะไร และทำตามมาตรฐานเดียวกัน บทใหม่จึงหน้าตาและคุณภาพเหมือนบท 15

## 1. โครงสร้างเว็บ

| ที่อยู่ | คืออะไร |
|---|---|
| `/` | หน้ารวม: การ์ดแยกตามบท |
| `/<บท>/` เช่น `/15/` | หน้าของบท: แบบจำลองจัดกลุ่มตามหัวข้อ มีแถบกระโดดไปแต่ละหัวข้อ |
| `/q/<รหัส>/` เช่น `/q/15-4-3/` | **ลิงก์สั้นถาวร** ที่ QR ในชีทชี้มา หน้านี้พาต่อไปที่แบบจำลอง |
| `/sims/<รหัส>.html` | หน้าแบบจำลองจริง |

- **รหัส** = `<บท>-<หัวข้อ>-<หัวข้อย่อย>` ตามชีท เช่น 15-4-3 คือบท 15 หัวข้อ 4.3 ถ้าหัวข้อย่อยเดียวมีสองแบบจำลอง ใช้หัวข้อย่อยที่ใกล้ที่สุดที่ยังว่าง ห้ามใช้ลำดับ 1, 2, 3 เพราะการแทรกทีหลังจะทำให้เลขเลื่อน
- **ห้ามลบหรือเปลี่ยนชื่อ `q/<รหัส>/`** เพราะ QR ที่พิมพ์แล้วแก้ไม่ได้ ตัวสร้างเว็บจะหยุดทำงานถ้ารหัสที่เคยมีหายไปจาก chapter.json
- ไฟล์ `index.html`, `<บท>/`, `sims/`, `q/` สร้างอัตโนมัติ ห้ามแก้ด้วยมือ

## 2. ไฟล์ต้นฉบับ

```
src/common/common.css, common.js   สไตล์กลางและตัวช่วย DP (วาดวงจร ลูกศร มิเตอร์ จัดรูปตัวเลข สมการ)
src/ch<บท>/chapter.json            เลขบท ชื่อบท ระดับชั้น ชื่อหัวข้อ และรายการแบบจำลอง (id, title, sections) เรียงตามชีท
src/ch<บท>/<รหัส>.html             แบบจำลองหนึ่งอัน
src/ch<บท>/tests/*.js              ชุดทดสอบ Playwright ของบทนั้น
src/tools/build_site.py            สร้างเว็บทั้งหมดในที่เดิม: python3 src/tools/build_site.py (รันจากรากของ repo)
src/tools/make_qr.py               สร้างภาพ QR และถอดรหัสตรวจซ้ำ
src/tools/sheetlib_sim_box.py      โค้ดกรอบ QR ในชีท (ฟังก์ชัน SIM ของ sheetlib.py)
```

ดูตัวอย่างโครงไฟล์แบบจำลองได้จาก `src/ch15/15-5-3.html` (สั้นและใช้ตัวช่วยครบ) และ `src/ch15/15-3-1.html` (วงจร)

## 3. ขั้นตอนทำแบบจำลองของบทใหม่

1. `git pull` ก่อนเริ่มทุกครั้ง ทำทีละแชท ถ้ามีหลายแชททำพร้อมกัน ให้แต่ละแชทแก้เฉพาะ `src/ch<บท>/` ของตัวเอง
2. อ่านชีทของบทนั้นทั้งเล่ม แล้วเสนอรายการจุดที่ควรมีแบบจำลองให้ผู้ใช้เลือก ไม่เกินราว 8–10 จุดต่อบท แต่ละจุดบอกรหัส หัวข้อ สิ่งที่นักเรียนจะได้ลอง และเหตุผลว่าทำไมภาพนิ่งในชีทไม่พอ
3. ทำต้นแบบหนึ่งอันก่อน ให้ผู้ใช้ลองบนมือถือ แล้วจึงทำที่เหลือด้วยแบบเดียวกัน
4. สร้าง `src/ch<บท>/chapter.json` (ดูของบท 15) และไฟล์แบบจำลอง
5. เขียนชุดทดสอบ (ข้อ 5) รันจนผ่านทั้งหมด
6. `python3 src/tools/build_site.py` แล้วเปิดดูหน้าบทและทุกแบบจำลองที่ความกว้าง 360 px ทั้งโหมดสว่างและโหมดมืด
7. commit แล้ว push (ข้อความ commit เป็นภาษาไทย บอกว่าเพิ่มหรือแก้อะไร) รอ GitHub Pages ราว 1 นาที แล้วตรวจหน้าเว็บจริง
8. ใส่กรอบ QR ในชีท (ข้อ 6)
9. เขียนรายการแก้ส่งผู้ใช้ทุกรอบ

## 4. มาตรฐานของแบบจำลอง

**รูปแบบไฟล์**
- หนึ่งแบบจำลองคือ HTML ไฟล์เดียวแบบ "ตัวหน้าเว็บ" (เริ่มด้วย `<title>` มี `<style>/*COMMON_CSS*/</style>` และ `<script>/*COMMON_JS*/ …</script>`) ตัวสร้างเว็บจะใส่ส่วนหัว HTML ให้
- ไม่ใช้ไลบรารีภายนอก ยกเว้นฟอนต์ Sarabun จาก Google Fonts
- ออกแบบสำหรับมือถือก่อน ไม่มีการเลื่อนซ้ายขวาที่ 360 px ปุ่มแตะง่าย โหลดเร็ว
- ใช้ตัวแปรสีใน common.css เท่านั้น จึงรองรับโหมดมืดอัตโนมัติ
- เปิด `window.__sim = {st, update, …}` ไว้ให้ชุดทดสอบตั้งค่าและอ่านผล

**ส่วนประกอบของหน้า (ตามลำดับ)**
- eyebrow "Daisy Physics · บท N ชื่อบท · หัวข้อ x.y" ถ้าเป็นเนื้อหาต่อยอด ต่อท้ายด้วย "· ความรู้เพิ่มเติม (ต่อยอด)"
- h1 ชื่อแบบจำลอง และ lead หนึ่งถึงสองประโยคว่าทำอะไรได้
- ภาพหลัก (SVG) พร้อมคำบรรยายใต้ภาพ ส่วนปรับค่า ตัวเลขที่อ่านได้ และการคำนวณแสดงทีละขั้นแบบใน Ex. ของชีท
- กล่องข้อความอธิบายที่เปลี่ยนตามสถานการณ์
- "ลองทำ" 2–4 ข้อ ข้อแรกควรให้ทำนายก่อนแล้วค่อยดูผล โดยเฉพาะเรื่องที่นักเรียนมักเข้าใจผิด คำตอบซ่อนใน `<details>`
- หมายเหตุท้ายหน้าบอกสมมติฐานของแบบจำลอง เช่น ถือว่าความต้านทานคงตัว และบอกสิ่งที่วาดขยายเกินจริง

**ให้ตรงกับชีท**
- สัญลักษณ์ คำศัพท์ และข้อตกลงเครื่องหมายเหมือนชีททุกอย่าง (เช่น I เป็นขนาด ค่าที่มีเครื่องหมายเขียนให้ชัดว่าเป็นค่าตามทิศที่กำหนด)
- ค่าตั้งต้นหรือปุ่มลัดตรงกับ Ex. ในชีท ตัวเลขที่ได้ต้องตรงกับคำตอบของ Ex. นั้น
- อ้างหัวข้อ รูป และ Ex. ด้วยเลขจริงของชีท
- ระบบสี: แดง = กระแสและประจุบวก, น้ำเงิน = อิเล็กตรอนและเส้นกราฟหลัก, ดำ = สัญลักษณ์วงจร, ส้ม = แสงและความร้อน, เทา = เส้นช่วย
- มิเตอร์และแบตเตอรี่ทุกก้อนมีเครื่องหมาย + และ − จุดที่มีชื่อมีจุดทึบ

**ตัวเลขและข้อความ**
- แสดงตามเลขนัยสำคัญที่เหมาะกับข้อมูล ใช้สัญกรณ์วิทยาศาสตร์เมื่อค่าน้อยกว่า 10⁻³ หรือตั้งแต่ 10⁵ ขึ้นไป ตัวเลข 5 หลักขึ้นไปเว้นวรรคทุก 3 หลัก ใช้ `DP.fmt`
- ขั้นถัดไปของการคำนวณใช้ค่าที่ปัดแล้วตามที่แสดง เหมือนชีท
- เครื่องหมายลบในสูตรและข้อความใช้ "-" ส่วน "−" ใช้เฉพาะเครื่องหมายขั้ว
- `DP.eqHTML`: ข้อความหลัง "|" กลายเป็นหมายเหตุตัวเล็ก ห้ามใช้ "|" เป็นค่าสัมบูรณ์
- ภาษาไทยกึ่งทางการ อ่านง่าย ไม่มีคำว่า "หนังสือ" หรือเลขหน้าหนังสือ

## 5. มาตรฐานการตรวจก่อนส่ง

- **ฟิสิกส์:** เขียนชุดทดสอบ Playwright ที่คำนวณคำตอบใหม่แยกจากโค้ดของหน้า (เช่น ตัวแก้วงจรแบบโหนดที่เขียนเอง) แล้วไล่ค่าหลายชุดรวมกรณีสุดขั้ว (ค่าเป็นศูนย์ ลัดวงจร วงจรขาด ค่าสูงสุดและต่ำสุดของตัวปรับ) เทียบกับตัวเลขบนหน้าทั้งที่แสดงในตาราง สมการ และข้อความ
- **ภาพเคลื่อนไหว:** ตรวจเชิงสถิติว่าเป็นไปตามฟิสิกส์ (เช่น ไม่ต่อแหล่งกำเนิดแล้วการลอยเลื่อนเฉลี่ยเป็นศูนย์ จำนวนที่นับผ่านสองหน้าตัดเท่ากัน)
- **Ex.:** ค่าตั้งต้นและปุ่มลัดได้ผลตรงกับ Ex. ในชีท
- **หน้าตา:** ไม่มีการเลื่อนซ้ายขวาที่ 360 และ 400 px (ดู `src/ch15/tests/sw.js`) ป้ายไม่ทับเส้น โหมดมืดอ่านได้ และไม่มี error ใน console
- รันชุดทดสอบได้ด้วย `NODE_PATH=$(npm root -g) node src/ch<บท>/tests/<ไฟล์>.js` หลังสร้างเว็บแล้ว (ชุดทดสอบเปิดไฟล์ใน `sims/`)

## 6. กรอบ QR ในชีท

- ชีทต้องอ่านเข้าใจครบโดยไม่ต้องสแกน แบบจำลองเป็นส่วนเสริม
- วางกรอบใกล้จุดที่สอนเรื่องนั้น เช่น ต่อจากรูปหรือข้อควรระวังที่แบบจำลองช่วยอธิบาย ก่อน Ex. ของหัวข้อนั้น หรือท้ายหัวข้อ ถ้าเป็นเนื้อหาต่อยอด ให้วางต่อจากกรอบต่อยอด
- **หน้าตา (เหมือนบท 15 v18):**
  - ตารางสองช่องกว้างเต็มบรรทัด กรอบเส้นเขียว `70AD47` พื้น `EEF6E8` และไม่แยกข้ามหน้า
  - ช่องซ้ายกว้าง 2900 twips: ภาพ QR กว้าง 2.8 cm รวมขอบขาว (ตัวรหัสราว 2.2 cm) และใต้ภาพพิมพ์ลิงก์สั้น `mairua54.github.io/q/<รหัส>` ขนาด 11 pt
  - ช่องขวา: บรรทัดแรก "**แบบจำลอง (สแกน QR):** ชื่อแบบจำลอง" ชื่อเดียวกับใน chapter.json และต่อด้วยหนึ่งถึงสองประโยคว่านักเรียนลองทำอะไรได้ ข้อความนี้ต้องตรงกับปุ่มที่มีจริง
- **ถ้าชีทของบทนั้นสร้างด้วย sheetlib.py ของชุด Daisy:**
  - ใช้ `src/tools/sheetlib_sim_box.py`
  - สร้างภาพด้วย `python3 src/tools/make_qr.py <โฟลเดอร์> --chapter <บท>`
  - หลังใส่กรอบ ตรวจว่าเนื้อส่วนอื่นของชีทไม่เปลี่ยน
- **ถ้ามีแค่ไฟล์ .docx:** ใส่กรอบตามสเปกเดียวกันลงใน .docx โดยตรง และเก็บไฟล์เดิมไว้
- **ตรวจ QR ทุกอัน:**
  - ถอดรหัสภาพด้วย OpenCV
  - แปลงชีทเป็น PDF แล้วถอดรหัสจากหน้าที่เรนเดอร์อีกครั้ง
  - ลิงก์ที่ได้ต้องตรงกับรหัส และหน้าเว็บต้องเปิดได้จริง
