แรงลัพธ์บนเส้นตรงและตำแหน่งที่แรงลัพธ์เป็นศูนย์

ตั้งจุดประจุ q1 และ q2 บนแกน x แล้วลากประจุ q0 ไปตามแกน ดูแรงจากประจุแต่ละตัวกับแรงลัพธ์ และหาตำแหน่งที่แรงลัพธ์เป็นศูนย์

แรงที่กระทำต่อ q0

แตะหรือลากบนภาพเพื่อเลื่อน q0 (วงกลมเล็ก) ลูกศร F1 (ชมพูเข้ม) คือแรงจาก q1 ลูกศร F2 (เขียวน้ำเงิน) คือแรงจาก q2 และลูกศร FR (เขียว) ด้านล่างคือแรงลัพธ์ แถบสีจางคือช่วงที่ q0 อยู่

ลองทำ

1. ทำนายก่อน: ประจุต่างชนิด จุดที่แรงลัพธ์เป็นศูนย์อยู่ช่วงไหน

กด "Ex. 1.9 ข" (q1 = +1.0 μC ที่ x = 0 และ q2 = -4.0 μC ที่ x = 0.90 m) ก่อนกดแสดงตำแหน่ง ให้ทำนายว่าจุดที่แรงลัพธ์เป็นศูนย์อยู่ทางซ้ายของ q1 ระหว่างประจุ หรือทางขวาของ q2 แล้วลาก q0 ไปทีละช่วงเพื่อตรวจคำทำนาย

คำตอบ ระหว่างประจุ F1 และ F2 ชี้ไปทาง +x ทั้งคู่ ทางขวาของ q2 แรงชี้สวนกัน แต่ q0 อยู่ใกล้ประจุที่ขนาดใหญ่กว่า F2 จึงมากกว่าเสมอ จุดที่แรงลัพธ์เป็นศูนย์จึงอยู่ทางซ้ายของ q1 ที่ x = -0.90 m ซึ่งแรงทั้งสองมีขนาด 0.011 N เท่ากัน

2. ประจุชนิดเดียวกัน (Ex. 1.9 ก)

กด "Ex. 1.9 ก" แล้วลาก q0 หาตำแหน่งที่ลูกศร F1 และ F2 ยาวเท่ากัน ตำแหน่งนั้นอยู่ใกล้ประจุตัวไหน เพราะอะไร

คำตอบ x = 0.30 m ใกล้ q1 = +1.0 μC ซึ่งมีขนาดเล็กกว่า แรงแต่ละแรงมีขนาด 0.10 N ประจุที่เล็กกว่าต้องอยู่ใกล้กว่าจึงออกแรงได้เท่ากัน โดย r2/r1 = √(4.0/1.0) = 2.0

3. เปลี่ยน q0 เป็นประจุลบ

วาง q0 ที่ตำแหน่งที่แรงลัพธ์เป็นศูนย์ แล้วกด "-1.0 μC" ลูกศรเปลี่ยนไปอย่างไร และตำแหน่งนี้ยังให้แรงลัพธ์เป็นศูนย์หรือไม่

คำตอบ F1 และ F2 กลับทิศทั้งคู่ แต่ขนาดเท่าเดิม แรงลัพธ์จึงยังเป็นศูนย์ ตำแหน่งนี้ไม่ขึ้นกับขนาดหรือชนิดของประจุที่นำมาวาง เพราะ q0 ตัดกันทั้งสองข้างของสมการ

4. ประจุต่างชนิดที่มีขนาดเท่ากัน

ตั้ง q1 = +4.0 μC และ q2 = -4.0 μC มีตำแหน่งที่แรงลัพธ์เป็นศูนย์หรือไม่

คำตอบ ไม่มี ระหว่างประจุ แรงทั้งสองชี้ทางเดียวกัน นอกช่วง แรงชี้สวนกัน แต่ q0 อยู่ใกล้ประจุตัวหนึ่งมากกว่าเสมอ แรงจากตัวที่ใกล้กว่าจึงมากกว่าเสมอ แรงลัพธ์เข้าใกล้ศูนย์เมื่ออยู่ไกลมากเท่านั้น

แบบจำลองนี้ถือว่า q1, q2 และ q0 เป็นจุดประจุที่ตรึงอยู่บนแกน x และใช้ k = 9.0 × 109 N·m2/C2 ภาพไม่ได้วาดตามมาตราส่วน ความยาวลูกศรเทียบกันได้เฉพาะลูกศรที่ตำแหน่งเดียวกัน เพราะแรงใกล้ประจุมีค่ามากจนลูกศรจะล้นภาพ เมื่อย้าย q0 จึงย่อมาตราส่วนลูกศรลง ลูกศรที่สั้นมากวาดด้วยความยาวขั้นต่ำเพื่อให้เห็นทิศ วงกลมของประจุวาดใหญ่กว่าจริงมาก จึงวาง q0 ห่างจากประจุน้อยกว่า 0.15d ไม่ได้ ภาพแสดงตั้งแต่ x = -1.2d ถึง 2.2d ถ้าจุดที่แรงลัพธ์เป็นศูนย์อยู่ไกลกว่านั้น หน้าจะบอกตำแหน่งเป็นตัวเลข ตัวเลขแสดง 2 ตัวตามเลขนัยสำคัญของข้อมูล และแรงลัพธ์คำนวณจากค่าที่ปัดแล้ว เหมือน Ex. ในชีท
